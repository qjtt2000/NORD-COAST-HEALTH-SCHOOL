# Nord Coast Health Institute Website

Static bilingual website prepared for GitHub Pages.

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `nord-coast-school`.
2. Upload **all files and folders in this package** to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. GitHub will provide the public URL after deployment.

## Files
- `index.html` — main website
- `styles.css` — all site styling
- `script.js` — bilingual toggle + mobile menu
- `assets/images/` — Nord Coast logo and school photos from supplied files
- `documents/` — public-facing school documents
